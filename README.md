# consultaManutencao

Sistema criado e hospedado pelo vercel(usando html, css, java script e apps script integrado com planilha sheets) para ser usado pelos motoristas da empresa, no qual servirá para input de informaçoes sobre os ônibus(código de solicitação, número do carro e matrícula do motorista) para que assim seja possível consultar os dados do veículo.
Será integrado também gráficos feito no power bi.
